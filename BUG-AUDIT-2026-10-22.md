# Audit penggabungan Ruang Belajar — 22 Oktober 2026

Status: temuan lokal di bawah sudah direproduksi, diperbaiki, dan diberi tes regresi. Pemeriksaan dilakukan langsung dalam sesi ini tanpa reviewer independen. Data pengujian sintetis; data pribadi dan database produksi tidak diubah.

## Bukti pengujian

- Tes baru gagal pada kode sebelum perbaikan untuk benturan ID, tanggal timezone, palet gelap, overflow grafik, konfirmasi login, respons autentikasi rusak, dan respons API yang tidak valid.
- Browser sebelum perbaikan mereproduksi draf akun A pada akun B, penimpaan editor tryout dua tab, kegagalan pemulihan offline, dan toast sukses setelah kuota gagal.
- `npm test`: suite semula ditambah `audit-regressions.test.mjs` dan `api-audit.test.mjs`.
- `tests/audit-browser.test.mjs`: lima skenario browser untuk pergantian akun, tryout dua tab, profil dua tab, cache offline, dan kegagalan kuota.
- `tests/account-browser.test.mjs`: regresi masuk/daftar, Remember me, impor tamu eksplisit, penyimpanan akun, logout, filter tracker, Back, dan akses keyboard.
- `tests/browser.test.mjs`: 13 rute dalam enam bahasa, alur timer/progres/tryout/tugas/kalender, tema, pratinjau impor beserta unduhan cadangan, serta pemeriksaan 390px tanpa kesalahan halaman atau overflow dokumen.
- Pemeriksaan sintaks dan `git diff --check` dijalankan pada perubahan saat ini.

Kode aktif, API, CSS, HTML, dan pengujian dirapikan dengan Prettier versi terkunci. Vendor dan berkas data sumber dipertahankan. `npm run format:check` menjadi pemeriksaan format yang dapat diulang.

Pemeriksaan katalog meliputi 3.114 pesan, kesamaan placeholder, kategori plural tiap bahasa, tanggal tidak valid, UK/US tanggal/jam, angka desimal Prancis, dan plural Rusia. Peninjauan tata bahasa/istilah dilakukan langsung; pengujian otomatis tidak dianggap sebagai penilaian penutur asli yang independen. Materi dan teks pribadi tidak diterjemahkan.

Pengujian tambahan: `localisation-audit`, `merge-boundaries`, `parity`, dan `stress` masuk ke `npm test`. `support-browser` (port 5202) menguji keenam bahasa pada halaman pendukung, panduan, validasi, callback, dan recovery. `http-server` (port 5203) menguji permintaan HTTP nyata; tidak memakai akun produksi. Stress menjalankan 1.800 aksi timer, 144 kasus cadangan buatan, dan oracle menit di tujuh zona waktu.

Pemetaan sumber ke implementasi dan batas transfer tercatat pada [FEATURE-PARITY.md](FEATURE-PARITY.md). Folder Sela tetap ada. Runtime serta tes menggunakan modul lokal Ruang, tanpa import ke folder Sela.

Hasil pemeriksaan akhir: `npm test` lulus untuk 15 suite, termasuk regresi atribusi PM/PK. Empat suite browser (alur utama, akun, audit, dan halaman pendukung) lulus. Regresi HTTP lokal, pemeriksaan sintaks 53 modul/pengujian, `npm run format:check`, serta `git diff --check` juga lulus. Render halaman verifikasi ponsel diperiksa setelah menyamakan tipografi dengan workspace. Tidak ada perubahan produksi selama pemeriksaan.

## Batas audit

Pengujian akun dan server menggunakan fixture, bukan akun produksi. Audit ini belum memverifikasi penerapan SQL, RLS/RPC nyata, pengiriman email, redirect produksi, atau sinkronisasi dua perangkat nyata. Tidak ada jaminan seluruh bug telah ditemukan. Panduan operasional tetap tersedia di MIGRATION.md dan AUTH.md.
